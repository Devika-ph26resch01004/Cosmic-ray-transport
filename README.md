# Cosmic-Ray Transport in Turbulent Magnetic Fields

## 1. Project Overview

This project investigates the parallel diffusion of energetic cosmic-ray protons in turbulent magnetic fields using numerical test-particle simulations.

The primary objective is to study the dependence of the parallel diffusion coefficient on particle energy and rigidity. The simulation approach is inspired by the work of Giacalone and Jokipii (1999), *The Transport of Cosmic Rays across a Turbulent Magnetic Field*.

Particle trajectories are obtained by numerically integrating the relativistic Lorentz equation in a prescribed, static, three-dimensional turbulent magnetic field. The parallel diffusion coefficient is estimated from the time evolution of the ensemble-averaged mean-square displacement along the direction of the mean magnetic field.

## 2. Project Objectives

- Investigate the parallel transport of energetic protons in turbulent magnetic fields.
- Calculate the parallel diffusion coefficient using the mean-square displacement method.
- Examine the dependence of the diffusion coefficient on particle kinetic energy and rigidity.
- Compare the numerical results with quasi-linear theory (QLT) and published results from Giacalone and Jokipii (1999).

The directory contains the simulation scripts, analysis scripts, and numerical results used in this project.

## 3. Software Requirements

The simulations and analysis use Python and the following packages:

- NumPy
- SciPy
- MPI4Py
- Numba
- Pandas
- Matplotlib

The package dependencies are listed in `requirements.txt`.

To install the Python dependencies, run:

```bash
pip install -r requirements.txt
```

An MPI implementation, such as Open MPI or MPICH, must also be installed separately for parallel execution using MPI.

## 4. How to Run the Simulations

### Step 1: Clone the Repository

Clone the repository to your local machine:

```bash
git clone https://github.com/YOUR_USERNAME/Cosmic-ray-transport.git
```

Navigate to the project directory:

```bash
cd Cosmic-ray-transport
```

### Step 2: Install the Dependencies

It is recommended to create a separate Python virtual environment:

```bash
python -m venv cosmic_ray_env
```

Activate the environment.

On Linux:

```bash
source cosmic_ray_env/bin/activate
```

On Windows:

```bash
cosmic_ray_env\Scripts\activate
```

Install the required Python packages:

```bash
pip install -r requirements.txt
```

An MPI implementation, such as Open MPI or MPICH, must also be installed to execute the simulations in parallel.

### Step 3: Run the Particle Simulation

Navigate to the simulation directory:

```bash
cd simulation_codes
```

The simulation is executed using the `ensemble_test_300.py` script, which calculates particle trajectories in the prescribed turbulent magnetic field generated using the `turbulent_field1.py` module.

To run the simulation using MPI, execute:

```bash
mpirun -np 4 python ensemble_test_300.py
```

Here, `-np 4` specifies the number of MPI processes. This can be changed depending on the available computational resources.

**Note:** The Python module imported in `ensemble_300_test.py` must match the actual filename of the turbulent field module.

### Step 4: Analyse the Simulation Results

After the simulations are completed, navigate to the analysis directory:

```bash
cd ../analysis_codes
```

The analysis scripts can then be executed to calculate the parallel diffusion coefficient, examine its dependence on particle rigidity, and generate plots.

For example:

```bash
python K_parallel_mean.py
python MSD_log_log.py
```

The analysis scripts use the ensemble mean-square displacement data generated by the simulations.

**Note:** Ensure that the input and output file paths specified in the Python scripts correspond to the locations of the simulation results on your local machine.

The ensemble mean -square displacement data generated for the 3 proton kinetic energies are given in the folder simulation results. You can use these MSD values and run the analysis codes, without running the simulations.
